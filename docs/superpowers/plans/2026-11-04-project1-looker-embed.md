# Project 1 Looker Studio Embed Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Replace Project 1's decorative artwork with the user's real, responsive Looker Studio dashboard.

**Architecture:** Keep the existing `ProjectCard` component and project data structure. Add the exact Looker Studio iframe source to Project 01, render a titled lazy iframe in its art area, and style that frame responsively. Keep a separate link to open the public report.

**Tech Stack:** React 19, Vite, CSS.

**Spec:** `docs/superpowers/specs/2026-11-04-project1-looker-embed-design.md`

## Global Constraints

- Use the exact iframe `src` generated by Looker Studio's **File → Embed report** dialog.
- The report is intended to be publicly viewable, as confirmed by the user.
- Make the iframe responsive, lazy-loaded, titled for screen readers, fullscreen-capable, and use the sandbox settings from the generated code. Keep a separate link to the report as a fallback.
- Preserve the existing responsive layout and the current presentation of Projects 2–6.
- Do not add dependencies or modify the Looker Studio report.
- Do not add or run tests unless the user asks for testing or verification.

## Review Focus

- A regular report-sharing URL must not be mistaken for an iframe embed URL; use the exact generated `src` supplied by the user.
- The iframe must have an accessible title and a separate report link.
- The iframe must not overflow the art region on narrow screens.
- Project cards 2–6 must keep their existing artwork and layout.
- Public access is configured in Looker Studio; the portfolio cannot grant report access itself.

### Task 1: Embed the live dashboard in Project 01

**Files:**
- Modify: `src/App.jsx` — add the generated embed URL to Project 01 and render the iframe and fallback link for that project only.
- Modify: `src/styles.css` — size and frame the iframe responsively within the existing Project 01 art area.

**Interfaces:**
- Consumes: the exact `src` copied from Looker Studio's generated iframe code.
- Produces: Project 01 displays the interactive report in its art area; other projects continue using their existing CSS artwork.

- [x] **Step 1: Add the supplied embed URL to Project 01**

Add an `embedUrl` property to the first project object using the exact URL supplied by the user: `https://datastudio.google.com/embed/reporting/f4e4c56d-6cd8-4cf3-8b4d-7a0f15758289/page/drU6F`. Keep the existing public report URL as a separate `reportUrl` for the fallback link. Do not construct or alter the embed URL.

- [x] **Step 2: Render the report for Project 01 only**

In `ProjectCard`, when `project.embedUrl` exists, render an iframe with `title="Dashboard Prediksi Tren Penjualan"`, `width="600"`, `height="717"`, `loading="lazy"`, `allowFullScreen`, and the sandbox value copied from the supplied iframe: `allow-storage-access-by-user-activation allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox`. Do not put `aria-hidden="true"` on the iframe or its container; keep the existing hidden decorative art markup for cards without `embedUrl`. Add a clearly labeled link using `project.reportUrl`, opening in a new tab with `rel="noopener noreferrer"`.

- [x] **Step 3: Add responsive iframe styling**

In `src/styles.css`, give the iframe a full-width responsive frame with a 600:717 aspect ratio matching the generated iframe dimensions, preserve the current art area's color treatment where practical, and ensure it stays within the card at desktop and mobile breakpoints.

- [x] **Step 4: Keep verification within the requested scope**

No automated tests are added or run unless the user asks for testing or verification.
