# Project 1 Looker Studio Embed

## Intent

Show the user's real sales-trend dashboard inside Project 1 so portfolio visitors can explore the work without leaving the page. The user confirmed that the dashboard may be public and chose an inline embed.

## Goals and non-goals

- Replace the decorative CSS artwork for Project 1 with a responsive, interactive Looker Studio report.
- Keep Project 1's description, technology tags, visual style, and the other project cards intact.
- Keep an accessible report title and a link to open the report separately.
- Do not change the dashboard itself, add dependencies, or embed other projects.

## Approaches

- **Inline iframe (selected):** show the real interactive report in the existing Project 1 artwork area. This matches the user's request and lets visitors use the dashboard on the portfolio page.
- **External link:** retain an artwork area with a link that opens the report in another tab. This is simpler and avoids loading the report in-page, but it does not meet the user's selected inline experience.

## Constraints and implementation calls

- Use the exact iframe `src` generated by Looker Studio's **File → Embed report** dialog. The regular report-sharing URL is not an embed URL.
- The report is intended to be publicly viewable, as confirmed by the user.
- Make the iframe responsive, lazy-loaded, titled for screen readers, and fullscreen-capable. Keep a separate link to the report as a fallback.
- Preserve the existing responsive layout and the current presentation of Projects 2–6.
- The user supplied the generated iframe URL, its 600×717 dimensions, and its sandbox settings. Use those values for the Project 01 embed.
